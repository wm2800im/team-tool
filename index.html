Comment fonctionne Covoiturage ?
L’application organise les trajets du groupe à partir des disponibilités de chacun et garde les compteurs de conducteurs équilibrés.
1. Renseigner le prochain jour
Dans Prochain, chacun indique son statut : Présent pour covoiturer normalement, Absent s’il ne participe pas, Seul s’il fait le trajet de son côté, ou Impératif s’il doit repartir à une heure précise.
2. Gérer un impératif
Avec Impératif, on choisit l’heure de départ. Les autres membres concernés peuvent indiquer s’ils sont compatibles avec cette contrainte, afin d’éviter de proposer un groupe impossible.
3. Proposition automatique
L’application utilise les personnes disponibles, les impératifs et l’historique pour proposer les groupes. Elle suggère aussi le conducteur qui a le moins conduit dans cette composition précise de groupe.
4. Conducteur réel et validation
Avant de valider, le conducteur réellement utilisé peut être choisi. C’est ce conducteur qui sera ajouté à l’historique et aux compteurs. En production, un trajet du jour est validable à partir de 7h ; dans cette version TEST, la validation est volontairement libre pour les démonstrations.
5. Planning
L’onglet Planning permet de renseigner plusieurs jours d’un coup, puis de modifier une journée individuellement. Les week-ends, jours fériés du Jura et exceptions d’entreprise sont gérés automatiquement.
6. Groupes
L’onglet Groupes permet de préparer ou corriger manuellement les groupes d’une date, notamment pour enregistrer fidèlement ce qui s’est réellement passé.
7. Historique et compteurs
Historique affiche les trajets enregistrés et le bilan personnel. Les compteurs de conducteurs sont propres à chaque composition : un binôme possède donc son propre équilibre, différent d’un trinôme ou d’un groupe plus grand.
8. Rappels
Si les notifications sont activées, un rappel peut être envoyé à 20h lorsque le prochain jour travaillé n’a pas encore été renseigné.
Le principe : chacun renseigne simplement sa situation ; l’application aide ensuite à constituer un groupe compatible et à faire tourner les conducteurs le plus équitablement possible.
