# Covoiturage 4.8.2 — production

Version issue de Covoiturage TEST 4.8.1-test.2, validée le 9 novembre 2026.

- Les personnes ayant accepté un impératif horaire sont regroupées prioritairement avec son auteur.
- Un refus explicite reste une incompatibilité stricte.
- Les accords sont prioritaires sur la minimisation des personnes seules.
- En attente de réponses, les groupes confirmés restent regroupés.
- Les refus et réponses attendues de tous les présents sont visibles dans le cadre existant, y compris hors groupe.
- Aucune nouvelle commande ni bouton de recalcul.
- Les groupes créés manuellement conservent leur composition.
- Configuration Firebase production, notifications de production et données de production préservées.

Régression couverte par les tests issus du dépôt TEST.
